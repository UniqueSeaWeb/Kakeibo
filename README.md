# かんたん家計簿

スマホで使える家計簿Webアプリ（PWA）です。インストール不要で、ホーム画面に追加するとアプリのように使えます。オフラインでも動作します。

## 主な機能

| 画面 | 内容 |
| --- | --- |
| 記録 | カテゴリをタップ → 金額入力 → 記録。メモは過去の入力から候補を表示 |
| 明細 | 月ごとの明細を日付別に表示。カテゴリで絞り込み、タップで編集・削除 |
| 集計 | 月の合計と前月比、分類別の割合、カテゴリ別の金額と前月比、12か月の推移グラフ |
| 設定 | 毎月の固定費の登録（毎月自動で記録）、CSV書き出し、バックアップ・復元 |

### カテゴリ

- **食費**：外食 / スーパー / コンビニ
- **光熱費**：電気 / 水道 / ガス
- **交通**：カーシェア
- **固定費**：家賃 / 通信 / サブスク / 保険 / その他固定
- **その他**

## 使い方

### GitHub Pages で公開する（おすすめ）

1. GitHub のリポジトリ「Settings → Pages」を開く
2. Source に「Deploy from a branch」、ブランチとフォルダ `/ (root)` を選んで保存
3. 表示された URL をスマホで開く
4. iPhone は Safari の共有ボタン →「ホーム画面に追加」、Android は Chrome のメニュー →「ホーム画面に追加」

### パソコンで試す

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## データの保存について

- 記録はその端末のブラウザ（localStorage）にのみ保存され、外部には送信されません。
- 機種変更やブラウザのデータ削除に備え、「設定 → バックアップを保存」で定期的にバックアップしてください。
- 「CSVで書き出す」で Excel や Google スプレッドシートに取り込めます。

## 構成

```
index.html            画面
css/style.css         スタイル（余白は 8 の倍数、ダークモード対応）
js/categories.js      カテゴリ定義
js/store.js           データ保存・固定費の自動記録
js/app.js             画面の処理
manifest.webmanifest  PWA 設定
sw.js                 オフライン対応（Service Worker）
icons/                アプリアイコン
```
